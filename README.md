# healthcare-device-sales-analytics
SQL-based healthcare device sales analytics project using synthetic sales data, MySQL, and business performance analysis.

## Project Overview

An end-to-end healthcare and commercial analytics project built using
Power BI and SQL to analyse aesthetic device sales, clinic revenue,
patient activity and machine performance.

The project demonstrates how transactional sales data can be transformed
into management-ready business insights using data modelling, DAX,
Power Query and interactive Power BI dashboards.

> Note: This project uses simulated/anonymised data created for portfolio
> and learning purposes. No confidential company or client data is used.

---

## Business Objective

The objective is to help healthcare and aesthetic clinic management
understand:

- Overall revenue performance
- Monthly revenue trends
- Machine-wise revenue contribution
- Branch performance
- Doctor-wise revenue contribution
- Patient activity and repeat-patient behaviour
- Revenue efficiency per transaction and session

---

## Dataset

The project uses two datasets:

### Sales Data

Contains transactional information including:

- Transaction ID
- Date
- Branch
- Doctor
- Machine
- Treatment
- Patient Type
- Sessions
- Revenue

### Machine Data

Contains machine-level information including:

- Machine ID
- Machine
- Category
- Purchase Cost

---

## Data Model

The Power BI model uses a relationship between:

`Machine_Data_Clean[Machine]`

and

`Sales_Data_Clean[Machine]`

with the machine table on the "one" side and the sales table on the "many" side.

A dedicated Date table is also used for time-based analysis.

---

## Power BI Dashboard

The dashboard provides:

### KPI Analysis

- Total Revenue
- Total Transactions
- Average Revenue per Transaction
- Total Sessions
- Revenue per Session
- New Patients
- Repeat Patients
- Repeat Patient %

### Performance Analysis

- Monthly Revenue Trend
- Revenue by Machine
- Branch Revenue Performance
- Doctor Revenue Performance

### Interactive Filters

- Date
- Branch
- Machine
- Doctor
